# ATLAS AI — projeto Android (código-fonte)
Inclui interface Android nativa com chat, entrada por voz, leitura em voz alta e lembretes locais, além de função Netlify para Gemini.
Este ZIP contém código-fonte, NÃO um APK compilado.
Antes de compilar, edite API_ENDPOINT em MainActivity.kt para a URL publicada da função Netlify.
Configure GEMINI_API_KEY como variável secreta no Netlify. Nunca coloque a chave no app ou no GitHub.
Para gerar o APK, abra o projeto em Android Studio e compile. A função Netlify deve ser implantada separadamente.
